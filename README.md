# 学習記録

2027年の転職に向けて、基礎学習・業務システムの設計理解・転職準備を記録します。

## ファイル構成

- 日報：`YYYY/MM/DD.md`（従来の形式を継続）
- 週次振り返り：`YYYY/MM/weekly/YYYY-MM-DD.md`（日付は振り返り実施日。本文に対象期間を記載）
- テンプレート：`templates/daily.md`、`templates/weekly.md`

日付は日本時間を基準とし、過去日の報告は報告対象の日付に保存します。

## 記録の進め方

1. 学習前に、使える時間・予定・前回の疑問を相談する。
2. 学習後に、取り組んだこと・分かったこと・疑問・実績時間を報告する。
3. 同じ日の日報に追記し、予定と実績を区別する。
4. 週1回、理解度・時間配分・次週の重点課題を見直す。

報告がない日は自動で日報を作成しません。学習時間や進捗は推測せず、未報告と明記します。助言は本人の理解・実績と区別します。既存の記録は残し、訂正時は変更理由を明記します。

## 公開する内容

業務の学びは一般化し、架空の例で記録します。社員・施設等の実データ、認証情報、非公開コード、社内固有の規程・画面・URLは掲載しません。書籍の内容は自分の言葉で要約します。
